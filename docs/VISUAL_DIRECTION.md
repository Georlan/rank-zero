# Direção visual inicial

Noite urbana escolar, azul petróleo e grafite, ciano para o Sistema e coral para o rival. Silhuetas geométricas de lutadores, horizonte urbano em camadas, linhas finas de interface e cartões codificados por função criam uma base original. A ilustração é deliberadamente provisória, não arte final de personagens. O efeito de clarão é um Tween real em Godot; feedback e regras não dependem de sua duração. Composição de referência 1280×720, redimensionada pela Godot.

Recursos: todos os desenhos são primitivas vetoriais geradas por código original deste projeto; a fonte padrão é fornecida pela Godot. Nenhum material de terceiros foi incorporado. Arte de personagem, ícones, tipografia e animação de golpes devem ser desenvolvidos e licenciados antes de uso comercial. Manhwa e deckbuilders citados no briefing são referências conceituais, não ativos copiados.
