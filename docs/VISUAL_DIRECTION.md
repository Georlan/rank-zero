# Direção visual inicial

Cobertura escolar urbana à noite, grafite e azul petróleo, com ciano para o Sistema e coral para ações ofensivas. Os lutadores ficam em lados opostos, com espaço para a leitura das intenções e dos estados. Cartas têm dimensões fixas, cores por função e textos oriundos dos dados de combate. O efeito de clarão utiliza Tween na Godot e não controla a resolução das regras.

A imagem `assets/art/rooftop_duel.png` foi gerada para este projeto com a ferramenta integrada de geração de imagens da OpenAI: cenário de cobertura escolar chuvosa à noite, dois lutadores originais em posições opostas, estética de ilustração de luta, sem texto ou interface. É um único cenário estático com personagens incorporados, não sprites ou animações independentes. A consistência visual das próximas poses e recursos ainda precisará ser trabalhada. Os painéis e cartas são desenhados em GDScript; a fonte é a padrão da Godot. Referências narrativas são conceituais e não foram incluídos ativos das obras mencionadas.
