# Recursos visuais

`art/rooftop_duel.png`: ilustração original gerada com a ferramenta integrada de imagens da OpenAI para o RANK ZERO. Prompt: cobertura escolar chuvosa à noite, dois lutadores originais em lados opostos, ilustração de luta com paleta azul petróleo e vermelho, sem texto ou interface. A imagem é cenário e personagens combinados, provisória. Cartas e painéis são desenhados pelo projeto; fonte padrão da Godot.

`art/fighter_protagonist.png`, `art/fighter_caio.png` e `art/rooftop_empty.png`: recursos gerados pela ferramenta integrada da OpenAI. Prompts: personagem protagonista original com jaqueta azul petróleo e guarda de boxe; rival original com jaqueta bordô, em guarda, voltado para o protagonista; cobertura escolar noturna e chuvosa sem pessoas. Personagens possuem transparência. As imagens são poses únicas, movimentadas por Tween, não animações quadro a quadro.
